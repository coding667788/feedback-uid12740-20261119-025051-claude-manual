实现离线服务分区策略审计器，输入是有限服务、部署组、历史/目标共同的标签和两个版本的规则。按源、目的实例当前采用的各自规则分别计算出站和入站，显式拒绝优先，匹配协议和闭端口区间；服务连接以片段表示。给定组内一次性切换、部署组依赖 DAG，以及一组任何阶段均须允许的连通性和始终禁止的连通性。

最多 16 个组，寻找从旧状态到全量目标、每步切换一个可用组且满足全部限制的合法序列。输出字典序最小序列；无解则报告完成组数量最多的可达状态，按完成组排序列表打破并列，加上该状态每个下一步的阻断证据。对所选计划输出各步实际双向许可的端口差分与规则出处，端口不能逐点展开。测试端点混合版本的瞬时暴露和断流、局部可行步骤通往死路、并列拒绝、单端点边界。用小规模独立穷举验证序列。

必需与禁止连通性可按服务对、协议和端口闭区间指定；一项约束内的每个已声明端口都要满足。依赖 DAG 表示前置组必须先切换。初始和最终状态也参与校验。

在 Windows 原生 Python 3.12 上完成，仅用标准库和 CPU。所有输入自行合成，在本地测试目录离线运行。交付源码、README、可重放的 cases.json、自动化测试。统一提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v，README 写明输入结构、错误码、边界示例和实测结果。预期值须由独立判定或明确断言得出，测试不得从被测实现反推期望结果。
